# 🗺️ Roadmap

The Academy is being built in nine phases, moving from a foundation of learning content toward a full Customer Success operating system. Full detail lives in the repository's `ROADMAP.md`.

| Phase | Focus | Status |
|---|---|---|
| 1 | Academy Foundation (modules, structure) | 🟢 Established |
| 2 | CS Enablement (SOPs, playbooks, templates, forms) | 🟢 Established / Expanding |
| 3 | AI Enablement (prompt library) | 🟢 Active |
| 4 | Integrated AI Workflows | 🟢 Active / Expanding |
| 5 | Reporting & Management Visibility | 🟡 Developing |
| 6 | Documentation Platform (this site) | 🟡 In Development |
| 7 | Training & Learning Experience (videos, quizzes) | 🔜 Planned |
| 8 | Certification (VCCSP) | 🔜 Framework established, implementation planned |
| 9 | Continuous Improvement | 🔜 Ongoing |

**Current direction:** progressing from Maturity Level 3 (Enabled) toward Level 4 (AI-Assisted), with the near-term priority on connecting existing content and closing content gaps in Templates, Forms, Playbooks, and CRM Guides — not adding more files.
