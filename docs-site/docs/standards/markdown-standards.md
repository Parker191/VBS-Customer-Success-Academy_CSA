# 📝 Markdown Standards

## Headings

- One H1 per file
- Use sequential heading levels
- Avoid skipping heading levels

---

## Lists

Prefer unordered lists for general information.

Use numbered lists only for sequential tasks.

---

## Tables

Use tables for:

- KPIs
- Meeting agendas
- Action items
- Comparisons

---

## Code Blocks

Always specify the language when applicable.

Example:

```bash
git commit -m "docs: update SOP"
```

---

## Checklists

Example:

- [ ] Draft completed
- [ ] Reviewed
- [ ] Approved
- [ ] Published
