# 🔖 Versioning Policy

The VBS Customer Success Academy follows semantic versioning.

## Version Format

Major.Minor.Patch

Example:

5.0.0

5.1.0

5.1.1

---

## Major Version

New sections

Major restructuring

---

## Minor Version

New modules

New SOPs

New templates

---

## Patch Version

Grammar fixes

Formatting improvements

Broken links

Typo corrections
