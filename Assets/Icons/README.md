# 🧩 Icons

A curated set of brand-consistent icons (navy `#1B2A4A`, transparent background) for use throughout Academy documentation, slides, and the docs site.

## Status

**27 icons complete** — covering the core concepts used across Modules, SOPs, Playbooks, and Templates (building, users, handshake, database, health/heartbeat, chart, clock, calendar, target, and more).

## Usage

These are sized at 256×256px, transparent background, single navy fill — safe to use on white or light backgrounds. For use on dark/navy backgrounds, re-render at white fill (see `Training Videos/` deck generation scripts for the rendering approach, built on `react-icons`).
