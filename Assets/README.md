# 🎨 Assets

## Purpose

This folder contains all visual resources used throughout the VBS Customer Success Academy.

---

## Folder Structure

- **Diagrams** – Workflow diagrams and process maps
- **Icons** – Icons used in documentation
- **Images** – General illustrations
- **Logos** – Brand assets
- **Screenshots** – Application screenshots
- **Templates** – Editable visual templates

---

## Guidelines

- Use PNG or SVG whenever possible.
- Keep filenames lowercase with hyphens.
- Optimize images before uploading.
- Store source files separately if needed.
