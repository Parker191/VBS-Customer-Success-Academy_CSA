## About

`Certificate of Completion Template.html` is a print/PDF-ready certificate design with placeholder fields (`{{RECIPIENT_NAME}}`, `{{SCORE}}`, `{{COMPLETION_DATE}}`, `{{CERT_ID}}`, `{{MANAGER_NAME}}`) to fill in per learner upon passing the Module 20 Final Assessment. Open in a browser and print to PDF, or use a templating step to auto-fill fields when certification is issued.
