# 📘 Documentation Style Guide

## Purpose

This guide defines the documentation standards used throughout the VBS Customer Success Academy to ensure consistency, readability, and maintainability.

---

# Document Structure

Every document should follow this order:

1. Title
2. Metadata
3. Purpose
4. Objectives
5. Main Content
6. Best Practices
7. Common Mistakes
8. Related Documents

---

# Writing Style

✔ Clear and concise

✔ Professional

✔ Customer-focused

✔ Action-oriented

✔ Avoid unnecessary jargon

✔ Use active voice whenever possible

---

# Formatting Standards

- Use H1 for document titles.
- Use H2 for major sections.
- Use H3 for subsections.
- Use bullet lists for readability.
- Use tables for structured information.
- Use checklists where applicable.

---

# Emoji Usage

Use emojis to improve navigation, not decoration.

Examples:

📌 Purpose

🎯 Objectives

📋 Checklist

💡 Best Practices

⚠️ Common Mistakes

📚 Related Documents

---

# Links

Always use relative links.

Example:

[Customer Health SOP](../SOPs/Customer%20Health%20Management.md)
