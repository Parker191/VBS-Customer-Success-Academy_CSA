## About

`Portfolio Dashboard (Sample).html` is a self-contained, browser-viewable mockup of the Manager/Leadership Dashboard described in the [Zoho CRM Reports & Dashboards Guide](../CRM%20Guides/Zoho%20CRM%20Reports%20%26%20Dashboards%20Guide.md). It shows:

- Portfolio-level KPI summary (accounts, ACV, renewals due, escalations, average health score)
- Customer Health Overview (RAG donut chart + breakdown)
- Account Health Detail table
- Revenue & Renewal Status
- Activity Snapshot

All customer names and figures are fictional, for illustration only. To build the live version, recreate this structure in Zoho CRM's report and dashboard builder using the fields defined in the [Health Score Field Mapping Guide](../CRM%20Guides/Zoho%20CRM%20Health%20Score%20Field%20Mapping%20Guide.md).

**To view:** open the `.html` file directly in any browser — no server or build step required.
