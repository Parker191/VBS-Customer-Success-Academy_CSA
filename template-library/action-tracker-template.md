## Purpose

A single running log of all open and closed action items for an account, consolidated across meetings, escalations, and reviews — so nothing gets lost between individual meeting minutes.

---

## Usage Notes

- Add a new row every time an action item is created, regardless of source.
- Update status weekly — don't let items sit at 🔴 Not Started for more than one review cycle without a note explaining why.
- Review this tracker at the start of every Business Review before discussing new topics.
- Archive completed items quarterly rather than deleting them — historical action history is useful for renewal conversations and audits.
