## Purpose

This guide defines the format, tools, and process for producing the 20 Academy training videos. All 20 scripts in `Training Videos/Scripts/` follow this standard.

---

## Format

- **Style:** Voiceover narration over slides, with screen-recording segments where a tool (Zoho CRM, Moodle, etc.) is being demonstrated.
- **Target runtime:** 5–9 minutes per module. This is a condensed, narrated summary of the module's core content — not a full read-through. Videos exist to orient and reinforce; the written Module remains the source of full detail.
- **Tone:** Conversational and direct, matching the Academy's written voice — practical, not corporate-scripted.

---

## Recommended Tools

| Purpose | Suggested Tool |
|---|---|
| Slide creation | PowerPoint / Google Slides / Claude for PowerPoint |
| Screen recording | Loom, OBS Studio, or Camtasia |
| Voiceover recording | Any USB microphone + Audacity, or built-in Loom/Camtasia narration |
| Editing | Camtasia, DaVinci Resolve (free), or CapCut |
| Hosting | Upload to Moodle directly, or host on an internal video platform and embed |

---

## Script Format

Every script in this folder follows the same structure:

1. **Header** — video type, target runtime, source module, version
2. **Learning Objectives Recap** — what the viewer should walk away knowing
3. **Slide-by-Slide Script** — each slide has a **Visual** description and a **Voiceover** block written to be read aloud
4. **Closing / Call to Action** — points the viewer back to the full written Module, relevant SOP, or Playbook
5. **Production Notes** — anything needing special handling (screen recordings, on-screen text, diagrams to pull from `Assets/Diagrams/`)

---

## Recording Workflow

1. Build slides from the script's Visual descriptions.
2. Record voiceover reading the Voiceover blocks — a natural pace is roughly 130–150 words per minute.
3. Record any screen-recording segments called out in Production Notes separately, then insert them in the edit.
4. Edit together, add simple slide transitions (avoid distracting animation).
5. Export at 1080p, upload to Moodle as a video resource or embed in the SCORM package alongside the matching module page.

---

## Review & Approval

- Each video should be reviewed by a CS Manager against the source Module before publishing, to confirm nothing was lost in condensing.
- Version each video file with the same version number as its source Module, so updates stay traceable.

---

## Status Tracking

Update the checklist in `Training Videos/README.md` as each video moves from **Script Ready** → **Recorded** → **Edited** → **Published**.
