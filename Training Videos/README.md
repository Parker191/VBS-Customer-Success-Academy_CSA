## Actual Video Recording

Scripts and decks give you everything needed to *produce* the videos, but the recording/editing step itself (reading the speaker notes aloud via PowerPoint's "Record Slide Show", or a screen-recording tool) hasn't been done for any module yet — that's a separate production task for whoever owns video creation.

## Files

- `Production Guide.md` — format standard, tools, recording workflow, review process
- `Scripts/` — one script per module, each with slide-by-slide voiceover text and visual cues
- Slide decks (`.pptx`) are delivered separately, not stored in this repo folder
