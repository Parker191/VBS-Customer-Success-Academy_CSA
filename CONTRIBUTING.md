# 🤝 Contributing

Thank you for your interest in contributing to the VBS Customer Success Academy.

## Guidelines

- Follow the existing module structure.
- Use consistent Markdown formatting.
- Keep examples relevant to Customer Success.
- Update the README when adding major content.
- Test all internal links before committing.

## Naming Convention

Use the following format for module files:

01 - Module Name.md

02 - Module Name.md

...

20 - Module Name.md

## Commit Messages

Examples:

feat: add Module 12

docs: update README

refactor: reorganize modules

fix: correct formatting in Module 10

Thank you for helping improve the academy!
