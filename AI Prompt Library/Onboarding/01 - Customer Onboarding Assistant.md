# 🚀 Customer Onboarding Assistant

## Purpose

Help a Customer Success Manager create a structured customer onboarding plan based on the customer's goals, requirements, stakeholders, services, and timelines.

---

## Prompt

```text
Act as an experienced Customer Success Manager responsible for customer onboarding.

Analyze the following customer information and create a practical onboarding plan.

Customer:
[Customer name or anonymized description]

Customer Type:
[New customer / Existing customer with new service]

Services Purchased:
[List services]

Customer Goals:
[What does the customer want to achieve?]

Expected Outcomes:
[What should success look like?]

Project / Service Scope:
[Describe the scope]

Timeline:
[Expected start date, milestones, deadlines]

Key Stakeholders:
[List customer and internal stakeholders]

Customer Requirements:
[List known requirements]

Technical / Operational Requirements:
[List requirements]

Communication Preferences:
[Preferred communication method and frequency]

Known Risks:
[List known risks or concerns]

Dependencies:
[List dependencies]

Prepare the onboarding plan using the following structure:

1. Customer Goal
2. Definition of Success
3. Onboarding Objectives
4. Key Stakeholders
5. Required Information
6. Onboarding Milestones
7. Customer Responsibilities
8. VBS Responsibilities
9. Communication Cadence
10. Risks and Dependencies
11. First 30-Day Priorities
12. Success Checkpoints
13. Questions the CSM Should Ask
14. Recommended Next Steps

Create a clear action-oriented plan.

Do not invent customer information.

Clearly identify missing information.

Prioritize customer outcomes rather than simply completing administrative tasks.

Recommend realistic milestones based only on the information provided.
```

---

# 🧪 Example Use Case

### Situation

A new customer has started using VBS for BIM modeling services.

They need:

- A kickoff meeting
- Project requirements confirmation
- File/document exchange
- Delivery expectations
- Communication cadence

### Example Input

```text
Customer:
New architecture firm

Services Purchased:
BIM modeling support

Customer Goals:
Increase project delivery capacity.

Expected Outcomes:
Receive accurate BIM models within agreed timelines.

Project Scope:
Initial BIM modeling project.

Timeline:
Project begins next week.

Key Stakeholders:
Customer project manager
VBS CSM
VBS delivery team

Customer Requirements:
BIM standards and project files.

Communication Preferences:
Weekly status updates.

Known Risks:
Project requirements are still being finalized.
```

---

# 🎯 Expected Output

The AI should create something like:

### Onboarding Objectives

1. Confirm project scope.
2. Collect required project files.
3. Validate BIM standards.
4. Establish communication cadence.
5. Confirm delivery expectations.

### Key Milestones

```text
Kickoff
   ↓
Requirements Collection
   ↓
Requirements Validation
   ↓
Project Start
   ↓
First Deliverable
   ↓
Customer Feedback
   ↓
Onboarding Review
```

### First 30-Day Priorities

- Complete kickoff.
- Finalize requirements.
- Establish delivery cadence.
- Monitor first deliverable.
- Capture customer feedback.
- Confirm success criteria.

---

# 📋 CSM Onboarding Checklist

Before considering onboarding complete:

- [ ] Customer goals documented.
- [ ] Success criteria confirmed.
- [ ] Stakeholders identified.
- [ ] Project scope confirmed.
- [ ] Required files received.
- [ ] Requirements validated.
- [ ] Communication cadence established.
- [ ] Delivery expectations confirmed.
- [ ] Risks documented.
- [ ] First milestone completed.
- [ ] Customer feedback collected.
- [ ] CRM updated.
- [ ] Transition to ongoing account management completed.

---

# ⚠️ Important

AI can help structure an onboarding plan, but it cannot replace the actual customer conversation.

The CSM should validate:

- Customer goals
- Scope
- Timelines
- Responsibilities
- Success criteria

with the customer and relevant internal teams.
